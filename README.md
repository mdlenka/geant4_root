# Geant4 prerequisites installation

## Visualisation
### Qt6

**Debian**
```
sudo apt install libqt6core6t64 libqt6gui6 libqt6widgets6 libqt6opengl6 libqt63dcore6 libqt63dextras6 libqt63drender6 qt6-base-dev
```

**Fedora**
```
sudo dnf install qt6-qtbase qt6-qtbase-devel qt6-qtbase-gui qt6-qt3d qt6-qt3d-devel
```

## Standard requirements

**Debian**
```
sudo apt install zlib1g zlib1g-dev libexpat1 libexpat1-dev
```

**Fedora**
```
sudo dnf install zlib zlib-devel expat expat-devel
```

## Others

**Debian**
```
sudo apt install libxmu-dev libxmu-headers libx11-xcb1 libx11-xcb
```

**Fedora**
```
sudo dnf install libXmu-devel libX11-devel libxcb libxcb-devel
```
